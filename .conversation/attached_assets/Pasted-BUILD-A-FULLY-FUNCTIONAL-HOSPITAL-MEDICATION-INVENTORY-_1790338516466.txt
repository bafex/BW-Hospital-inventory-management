BUILD A FULLY FUNCTIONAL HOSPITAL MEDICATION INVENTORY MANAGEMENT WEB APP

You are a senior full-stack software engineer and UI/UX designer.

Build a fully functional, secure, responsive and reactive web application based on the project requirements below.

The application is for:

Republic of Botswana — Ministry of Health
Hospital Medication Inventory Management System

The system is designed for hospital-level medication inventory management in Botswana public hospitals.

IMPORTANT: This is NOT a Central Medical Store (CMS) distribution-tracking dashboard. CMS remains the supplier. The application manages what happens inside the hospital: receiving medicines, stock tracking, dispensing, chronic collection scheduling, alerts, replenishment preparation, reporting and auditing.

8. DISPENSING / ISSUING MEDICINE

Create a professional dispensing interface.

Allow the user to issue:

* Full packs
* Loose units

The system must:

FEFO

Use:

First Expiry First Out

The system automatically selects the oldest unexpired batch first.

The system must:

* Exclude expired stock
* Prevent over-issuing
* Prevent negative stock
* Calculate remaining stock
* Update stock automatically
* Record the transaction
* Create an audit log

Every issue MUST require:

* Medicine
* Quantity
* Patient/facility reference where applicable
* Prescription reference number
* User
* Date/time

An issue must not be saved without the prescription reference.
